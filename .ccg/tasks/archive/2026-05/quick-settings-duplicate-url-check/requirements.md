# 快速设置 URL 重复检测

## 用户需求

在快速设置向导的站点 URL 输入框中，用户点击“检测”时同时检查数据库里是否已经存在相同的网站 URL。如果已经存在，不继续新增，并询问用户是否跳转到该站点对应的渠道页面。

## 实施边界

- 仅修改快速设置 Step1 的交互，不新增后端接口。
- URL 去重基于现有 `useSiteList()` 数据，并在用户点击检测或提交时通过 `refetch()` 刷新最新站点列表。
- 命中重复时跳转到已有 `site-channel-card` 目标，由现有 `useJumpStore` 和渠道页 tab-store 负责切换到站点渠道页并定位。
- 提交前也必须再次拦截相同 URL，避免用户跳过“检测”直接创建。
